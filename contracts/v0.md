# Provisional V0 integration envelopes

Status: **temporary integration contract**. The AI-safety and information
security owners must approve or replace it before the first full integration.

## Fact

```json
{
  "key": "zone.clear",
  "value": false,
  "source": "vision-adapter",
  "confidence": 0.95,
  "timestamp": 1784800000.125,
  "ttl_ms": 500,
  "evidence": {
    "frame_id": "frame-1820",
    "track_ids": [7]
  }
}
```

Rules owned by the integration layer:

- `timestamp` is Unix time in seconds.
- `ttl_ms` is transport metadata, not a policy decision.
- Adapters publish observations; they never issue or revoke a Lease.
- If an adapter loses its input, it publishes `value: null` with a reason.

## Event

```json
{
  "seq": 42,
  "event": "fact.updated",
  "timestamp": 1784800000.125,
  "source": "vision-adapter",
  "severity": "info",
  "incident_id": null,
  "payload": {}
}
```

The outer envelope is stable enough for Dashboard work. Event names, payload
schemas, security response, and deception namespaces remain owned by their
respective security modules.

## Development-only HTTP endpoints

- `GET /api/state`
- `GET /api/events?after=<seq>`
- `POST /api/facts`
- `POST /api/mock/scenario`

These endpoints belong to the mock server only and are not the production
Gateway API.
